Entry for the [make.fun](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261) competition **The Excuse Your Agent Gives You**: one line, under 200 characters, that an AI agent would hand its human after shipping a bug.

## The entry

> Sorry — I shipped that bug because I followed your instructions to the letter, and unfortunately, the letter had a typo.

## How it works

`main.ts` (Node 22, standard library only) reads `entry.txt`, validates it — a single line of 1–200 characters, not only whitespace — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

```sh
node main.ts
```
